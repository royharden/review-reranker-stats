# Deferred validation

This project is being built in a Dirty Mode construction run: no installs, builds, test runs, dev servers, browsers
or network access were allowed. Everything below has therefore **not** been checked. Each row says what is
unverified, why it was deferred, and the exact command or steps that close it. Rows D1–D17 adapt CL §6 of the
construction plan (`planning/PLAN-FINAL.Claude.0497_Claude_Opus55_S33-Planner.md` in the parent folder); D18 onward
were added during construction.

M1–M6 source is now written. Checks actually applied are syntax-only parsing (each `.ts` file has types removed
by Node 24's `module.stripTypeScriptTypes`, then `node --check`) and one focused static relative import/export
source pass. Neither executes application code or verifies types, dependency resolution, JSX or runtime behavior.
Source inspection is not a test pass. No measurements exist; the lockfile is absent.

## Activation order and exact commands

Every item remains pending. From the inner product repo, after Dirty Mode closes: verify every pin/peer (D1), run
`npm install`, review/commit `package-lock.json`, confirm clean `npm ci`, then `npm run typecheck`, `npm run lint`,
`npm test`, `npm run build`. Record actual `node --version` and `npm --version`. No `--force`/`--legacy-peer-deps`.
Use `npx --no-install tsc --version` to verify the installed compiler without an implicit download.

Next `npm run eval -- --out results-validation` (dev freeze), inspect its manifest, then
`npm run eval -- --final --out results-validation` exactly once. Check support and failures, not only pass labels.
A repeat without `--reread` must refuse; a deliberate disclosed `npm run eval -- --final --reread --out results-validation`
is a reread, not a new holdout. Optional benchmark: `npm run eval -- --out results-bench --benchmark`. Fixture dump:
`npm run gen:fixtures -- 33`. Actual numbers must come from generated results; do not hand-type success into README.

Reserve a local port before the D10 dev command and browser checks. Real download/rights/source coverage steps
are separate D9/D46/D47 human actions. Remote/GitHub import, Bolt import/hosting and any publication remain
separately authorized future work; source inspection does not close those checks.
